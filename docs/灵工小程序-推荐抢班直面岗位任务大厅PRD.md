## 1. 公共门禁与页面地图

### 1.1 动作门禁（报名 / 抢班 / 领任务）

`ensureActionAllowed` 顺序固定，AND：

| 顺序 | 条件名 | 判定逻辑 | 拦截表现 | 确认后去向 |
|------|--------|----------|----------|------------|
| 1 | 实名 | `realNameVerified` 或档案 basicProofs 已核验实名 | 弹窗「请先实名认证」 | `/miniapp/onboarding?step=realname` |
| 2 | 人脸时效 | 未核验，或距 `faceVerifiedAt` 超过 2h/4h（按时间戳取模） | 弹窗「请进行人脸识别」 | `/miniapp/face-verify/capture?from={grab\|job\|claim}` |
| 3 | 部门入驻 | 仅 `requireDepartment` 时：须为该企业正式部门在职，非待入驻、非企业根 | 无在招岗 toast「您暂时无法报名…」；有岗弹窗引导岗位报名 | `/miniapp/recommend/job/{jobId}` |

抢班提交另有：培训考核闸、请假日拦截、重复报名、班次未上架/已满。  
任务领取另有：接任务课闸、任务期内请假、每人上限、总名额。

### 1.2 点击跳转总表

| 页面 | 路径 | 从哪进来 | 点击后去向 |
|------|------|----------|------------|
| 推荐 | `/miniapp/recommend` | 底栏「推荐」；工作台/日历「去抢额外班次」 | 切 Tab；进班次/面试/岗位详情；立刻抢班 |
| 抢班详情 | `/miniapp/recommend/shift/:teamId` | 班次卡头部或「全部」 | 多选班次报名；订阅（仅本地） |

### 1.3 检索总原则

**当前无用户侧多条件检索。** 推荐页城市固定展示「上海市」，不可点、不参与过滤。岗位偏好不进入推荐排序。任务大厅无关键词、无分类 Tab。下文「过滤」均为系统硬条件，逻辑为 AND。

## 2. 推荐 · 抢班

### 2.1 推荐首页 · Tab「抢班」

**路径：** `/miniapp/recommend`（默认或 `?tab=shifts`）  
**功能：** 信息流先渲染全部抢班面试卡，再渲染全部班次卡。预览条数上限 5。登录即可浏览。

#### 页面功能与点击

| 点击 | 结果 |
|------|------|
| 城市「上海市」 | 无点击、无筛选 |
| Tab「岗位招聘 / 抢班」 | `router.replace` 写 query，不刷新身份 |
| 面试卡整卡 / 头 / 「全部」 / 时段行 | `/miniapp/recommend/interview/:postId`，时段可带 `?slot=` |
| 班次卡头部 / 「全部」 | `/miniapp/recommend/shift/:teamId`（整卡不可点，仅头部可点） |
| 「立刻抢班」 | 本页直接报名，不进详情；过门禁后 `submitGrabShiftApplication` |
| 「加载更多」 | 仅 toast「加载更多（演示）」，不翻页 |

空态：「暂无抢班班次或面试岗位」。  
立刻抢班成功：白名单 toast「抢班成功，已自动通过」；否则「抢班成功，待审核」。

#### 交互：系统过滤（无检索框）

| 字段名 | 控件 / 文本 | 逻辑 |
|--------|-------------|------|
| 城市 | 固定文案「上海市」 | 不生效，不过滤；与岗位 city 无关 |
| 岗位偏好 | 档案兼职偏好 | 不生效，不排序、不隐藏 |
| 班次开放 | 系统 | `publishStatus` 为空或 `published` **且** `status` ∈ `open` / `partial` |
| 面试可见 | 系统 | 企业 `requireInterview=true` 且未来 21 天有时段 |
| 列表顺序 | 系统 | 面试卡全部在前；班次卡按日期 + 开始时间升序 |
| 白名单标签 | 系统 | 非白名单班次卡去掉「免审核」；面试卡不过滤该标签 |

#### 字段说明：面试卡

| 字段名 | 字段类型 | 是否必填 | 显示要求 | 交互说明 | 其他备注 |
|--------|----------|----------|----------|----------|----------|
| 标题 | 文本 | 展示必填 | 品牌前 8 字 \| 岗位名【直面岗位】，最多 2 行 | 点整卡进详情 | 品牌为企业名去掉「中国移动/分公司/有限公司」 |
| 标签 | 标签 | 否 | 最多 5 个；直面蓝、免审核绿 | 只读 | 写死：直面、免审核、星级补贴、近期发布、专属福利 |
| 时薪 | 金额区间 | 展示必填 | 红字 + /小时 · 上岗后收入 | 只读 | 部门班组 hourlyRate 最小~最大；缺省 20~23 |
| 门店名 | 文本 | 展示必填 | 部门名，否则品牌 | 只读 | — |
| 位置 | 演示文案 | 否 | 区 + km + 地铁口米数 | 只读 | 按 positionId 哈希生成，非真实定位 |
| Logo | 字符 | 展示必填 | 企业名首字，黄圆 | 只读 | — |
| 面板标题 | 文本 | 展示必填 | 「可面试时间」 | 只读 | — |
| 全部(N) | 链接 | 条件显示 | slotCount>5 才显示 | 进详情 | — |
| 面试时段 | 时间行 | 展示必填 | MM月DD日 周X HH:mm~HH:mm，最多 5 条 | 点行进详情并预选 | 满员或本人 pending 已报则不可点 |
| 时段收入 | 文本 | 展示必填 | 「收入面议」橙色 | 只读 | — |
| 容量 | 分数 | 展示必填 | 已约 / 每单元席位 | 只读 | 满员计数排除未到面、未通过 |
| 立刻抢班 | 按钮 | — | 面试卡不渲染 | 无 | 仅班次卡有此按钮 |

#### 字段说明：班次卡

| 字段名 | 字段类型 | 是否必填 | 显示要求 | 交互说明 | 其他备注 |
|--------|----------|----------|----------|----------|----------|
| 标题 | 文本 | 展示必填 | 企业名\|岗位名 | 仅点头部进详情 | 企业由考勤组解析；岗位优先 slot.positionName |
| 标签 | 标签 | 否 | seed extra.tags | 只读 | 非白名单去掉「免审核」 |
| 时薪区间 | 金额 | 展示必填 | ¥min~max/小时 · 日结上岗 | 只读 | 预览班次小时薪 |
| 门店 / 位置 | 文本 | 展示必填 | storeName；distance · commute | 只读 | getGrabShiftPostExtra |
| 面板标题 | 文本 | 展示必填 | 「可抢班次」 | 只读 | — |
| 全部 / 共 N 个 | 链接或文本 | 展示必填 | >5 显示全部，否则共 N 个 | 全部进详情 | 面试卡不显示「共 N 个」 |
| 班次时间 | 日期时间 | 展示必填 | M月D日 周X HH:mm~HH:mm | 行不可点 | — |
| 收入 | 金额 | 展示必填 | ¥pay · 单价元/小时 | 只读 | 单价=pay/时长，或 effectiveHourlyRate，缺省 22 |
| 容量 | 分数 | 展示必填 | 已抢/需求人数 | 只读 | 分母是 requiredCount，不是后台 enrollCap |
| 立刻抢班 | 按钮 | 操作 | 未报且有余可点；已报显示「已报名」 | 过门禁后本页提交 | 部门入驻+实名+人脸；白名单自动通过 |

### 2.2 抢班详情

**路径：** `/miniapp/recommend/shift/:teamId`  
**功能：** 聚合该班组所有开放班次。封面优先部门 `imageUrl`。底栏：已选数量、订阅、报名。无班次时空态「暂无可用班次」，底栏隐藏。

#### 页面功能与点击

| 点击 | 结果 |
|------|------|
| 班次格子 | 多选/取消；已报或无名额不可选 |
| 任职要求展开/收起 | 仅有职责列表时显示 |
| 订阅 | 仅本地状态，不落库；toast 已订阅/已取消 |
| 报名 | 未选中时 disabled；循环提交所选班次，留在本页并清空选择 |

#### 字段说明

| 字段名 | 字段类型 | 是否必填 | 显示要求 | 交互说明 | 其他备注 |
|--------|----------|----------|----------|----------|----------|
| 部门封面 | 图片 | 否 | 16:9；无图显示部门名 | 不可点 | department.imageUrl 或 seed |
| 标题 | 文本 | 展示必填 | 企业名\|岗位名 | 只读 | 与列表一致 |
| 标签 | 标签 | 否 | 非白名单去免审核 | 只读 | — |
| 店名 / 地址 / 距离通勤 | 文本 | 展示必填 | 三行 | 地图占位不可点 | getGrabShiftPostExtra |
| 免费保障 | 说明条 | 展示必填 | 固定文案出勤保险 | 不可点 | — |
| 班次格子 | 多选卡片 | 报名至少 1 | 日期、时段、班Xh、¥pay；已报角标；选中勾 | 点选切换 | 不展示余量人数 |
| 岗位类型 | 文本 | 否 | 空显示 — | 只读 | 发布快照 positionProfile |
| 年龄 | 文本 | 否 | min–max岁 / X岁以上/以下 / 不限 | 只读 | formatGrabPositionAgeRange |
| 性别 | 枚举 | 否 | 男 / 女 / 不限 | 只读 | — |
| 经验 | 文本 | 否 | 空显示不限 | 只读 | — |
| 任职要求 | 长文本 | 否 | 首行为 intro；其余行为职责，默认可收起 | 展开/收起 | 无内容显示暂无任职要求 |
| 岗位描述 | 长文本 | 否 | 有 description 才整段显示 | 只读 | — |
| 技能要求 | 列表 | 否 | 画像 skills → 班次 requirements → seed | 只读 | 空：暂无技能要求 |
| 报名贴士 | 规则组 | 展示必填 | 取消班次 / 补卡 / 打卡规则 | 只读 | 与招聘共用默认规则 |
| 订阅 | 按钮 | 否 | 心形文案 | 仅本地，不落库 | — |
| 报名 | 主按钮 | 是 | 未选中时 disabled | 批量提交 | 部分成功会汇总自动通过数 |

### 2.3 抢班面试详情

**路径：** `/miniapp/recommend/interview/:postId`，query `slot` 可预选。  
**功能：** 选时段报名。**不校验部门入驻**。成功后留在本页，时段变为已报名。灵工端没有「我的报名」面试列表。

#### 页面功能与点击

| 点击 | 结果 |
|------|------|
| 流程「详情」 | toast：选时锁定名额 → 线下面试 → 通过后优先抢班 |
| 保险条 | toast「出勤保险说明（演示）」 |
| 全部 / 收起 | 默认 6 条 ↔ 最多 24 条（未来 21 天） |
| 面试时间卡 | 单选；满员或已报不可选 |
| 星级权益 | toast 演示 |
| 立即报名 | 未选：「请先选择面试时间」；已报/满员对应提示；成功 toast「报名成功，请按时参加面试」 |

#### 字段说明

| 字段名 | 字段类型 | 是否必填 | 显示要求 | 交互说明 | 其他备注 |
|--------|----------|----------|----------|----------|----------|
| 标题 | 文本 | 展示必填 | 含【直面岗位】 | 只读 | — |
| 标签 | 标签 | 否 | 直面蓝、免审核绿 | 只读 | 不做白名单过滤 |
| 时薪 | 金额 | 展示必填 | 同列表 · 上岗后收入 | 只读 | — |
| 地点 | 文本 | 展示必填 | 主行店名+地铁口；副行区+距离 | 只读 | 演示文案 |
| 要求行 | 拼接文本 | 否 | 技能首条 · 经验 · 身高不限 | 只读 | 健康证改写为需要食品类健康证；经验空则「高中及以上」 |
| 报名直面流程 | 三步 | 展示必填 | 选时 / 线下面试 / 日常抢班 | 「详情」toast | 写死文案 |
| 免费保险 | 说明条 | 展示必填 | 同抢班 | 点击 toast 演示 | — |
| 面试时间卡 | 单选卡片 | 报名必填 | 默认 6 条，全部最多 24 | 点选 | 底部：收入面议 / 已报名 / 已满 |
| 星级权益 | 卡片 | 否 | 企业星级灵工 · 1项权益 | 点击 toast 演示 | — |
| 立即报名 | 主按钮 | 是 | 已报该时段则「已报名该时段」且禁用 | 校验时段后提交 | from=grab，requireDepartment=false |

报名写入（页面不展示）：enterpriseId、departmentId、姓名、手机、岗位、interviewDate、timeSlotId、timeSlotLabel、weekday、employeeId、status=pending。

## 4. 任务大厅

上架条件：`status === 'active'` **且** `dispatchMode === 'hall'`。指派任务、草稿/待审/已结束不进大厅。

### 4.1 任务大厅首页

**路径：** `/miniapp/task-hall`  
**功能：** 按**企业名称**（不是 ID）分组。每组预览最多 5 条；价格区间和标签只基于这 5 条。空态「暂无大厅任务」。

#### 页面功能与点击

| 点击 | 结果 |
|------|------|
| 顶栏里程表 | `/miniapp/tasks`；角标为待我操作数，>9 显示 9+ |
| 企业头 / 「全部(n)」 | `/miniapp/task-hall/enterprise/:id/tasks?name=企业名` |
| 「立刻领取」 | 阻止冒泡；门禁后去领取页，不进详情；`canClaim=false` 灰禁且无 toast |

#### 交互：系统过滤（无检索框）

| 字段名 | 控件 / 文本 | 逻辑 |
|--------|-------------|------|
| 上架 | 无 | status=active AND dispatchMode=hall |
| 分组 | 无 | key = enterpriseName 首次出现顺序。同名不同 ID 会并组；同 ID 不同名会拆卡 |
| 预览 | 「全部(n)」进企业页 | 每组 slice(0,5)；大厅价/标签不看第 6 条及以后 |
| 分类 / 城市 / 关键词 | 无输入框 | 未接入；seed 分类配置未使用 |

#### 字段说明

| 字段名 | 字段类型 | 是否必填 | 显示要求 | 交互说明 | 其他备注 |
|--------|----------|----------|----------|----------|----------|
| 企业名称 | 文本 | 展示必填 | 最多 2 行 | 点头进企业列表 | 分组 key |
| 标签 | 标签 | 否 | 预览任务去重最多 5；空则高佣金+长期 | 只读 | tagToneMap 着色 |
| 价格区间 | 金额 | 展示必填 | ¥min~max 起 · 按次/件结算 | 只读 | 仅预览 5 条 |
| 行业标签 | 文本 | 展示必填 | 运营商/零售/餐饮/快消等 | 只读 | 未知 → 企业服务 |
| 可领数量 | 数字文案 | 展示必填 | n 个任务可领 | 只读 | 组内全量条数 |
| 品牌字母 | 字符 | 展示必填 | 企业名首字黄圆 | 只读 | — |
| 槽位任务名 | 文本 | 展示必填 | 实际是任务名 | 行不可点，只点立刻领取 | — |
| 收入+名额 | 文本 | 展示必填 | 价格 · 剩余 n 名额 / 不限名额 | 只读 | remain>9999 视为不限 |
| 参与人数 | 数字 | 展示必填 | n人 | 只读 | acceptedCount |
| 立刻领取 | 按钮 | 操作 | canClaim=false 灰禁 | 要部门入驻 | 仅大厅按钮使用 canClaim |

## 5. 实现缺口（评审时确认）

1. 城市「上海市」不可选、不过滤；岗位 city 与展示城市可不一致。
2. 岗位偏好不进推荐排序/过滤。
3. 「加载更多」、订阅、在线沟通、保险/流程/星级/促销多为演示 toast，不落库。
4. 抢班面试报名不进入「我的报名」；灵工无法查看面试审核结果。
5. 招聘详情 seed 有面试时段，页面未用。
6. 灵工侧抢班余量用 `requiredCount` 而非后台 `enrollCap`。
7. 面试卡标签含「免审核」，但面试报名无白名单逻辑。
8. 任务大厅无搜索/分类；分组按企业名不按 ID。
9. 领取页预估金额与实例结算金额口径可能不一致。
10. 已取消实例仍计入每人领取上限。
